# Pressing Episode Feature Schema

2026-09-08. Generated by `pressing_structure/analytics/
export_pressing_features.py` →
`pressing_structure/outputs/research_dataset/pressing_episode_features.parquet`.
**Measured on the real clip: 19 rows (one per real V4 episode), 0
skipped, 59 columns.** Every feature is computed by
`pressing_structure/analytics/pressing_features.py`, which only
aggregates the SAME already-existing, already-tested analytics
(`pressing_v4.frame_features`, `pressure_field.team_pressure_field` and
friends) at each episode's real FSM-detected `onset_frame` — no new
pressure math.

## Identity / episode metadata

| column | type | meaning |
|---|---|---|
| `episode_id` | str | `pressing_v4`'s own id (`T{team}-{onset_frame}`) |
| `match_id` | str | constant `testVideo1_120s` today; required for match-grouped splits once more matches exist |
| `frame`, `time_sec` | int, float | the anchor frame (= `onset_frame`) |
| `pressing_team`, `ball_carrier_team` | int (0/1) | real, from the FSM/role resolution |
| `carrier_track_id` | int | the real resolved carrier at onset |
| `onset_frame`, `onset_time`, `active_start`, `end_frame`, `end_time` | — | `pressing_v4.build_pressing_v4` episode fields, unchanged |
| `termination_reason` | str | `EVIDENCE_EXPIRED` / `CONTEXT_CHANGED` / `FORMING_ABORTED` / `SCORE_ENDED` / `CLIP_END` |
| `supported_duration_sec`, `observations` | float, int | real evidence-support accounting from the FSM |
| `max_state_reached` | str | `ACTIVE_PRESS` if `active_start` is set, else `PRESS_FORMING` (on this clip: always `PRESS_FORMING`, 19/19) |

## `geom_*` — GEOMETRY (10 features)

`nearest_presser_distance_cm`, `second_presser_distance_cm`,
`mean_presser_distance_cm`, `n_within_3m`, `n_within_5m`, `n_within_8m`,
`first_presser_angle_deg`, `second_presser_angle_deg` (atan2 of
defender-relative-to-carrier displacement, degrees),
`local_numerical_superiority` (= `frame_features`'s own
`support_minus_opponents`, reused not recomputed), `compactness_cm`
(mean pairwise distance among defenders within 8m — `None` if <2),
`convex_hull_area_cm2` (scipy `ConvexHull` area of all pressing-team
defenders this frame; `None` if <3 non-collinear points).

## `motion_*` — MOTION (5 features)

`nearest_presser_closing_cm_s`, `presser_velocity_toward_carrier_cm_s`,
`n_participants` (real FSM `participant_ids` count — opponents within
5m closing ≥100cm/s), `supporting_player_convergence_cm_s` (mean
closing speed of participants, `None` if none), `carrier_speed_cm_s`.

## `escape_*` — PASSING / ESCAPE (6 features)

`n_teammates_considered`, `mean_lane_pressure`, `max_lane_pressure`
(across all real teammate passing lanes, from `passing_lane_metrics`),
`min_defender_to_lane_distance_cm` (min across all lanes),
`n_low_pressure_lanes` (lanes with mean pressure below `CONTOUR_LOW`
=0.35, the same calibrated ~1.5s-reach threshold the dashboard's own
contours use), `best_escape_direction_pressure` (from
`escape_directions`, single best of 8 radial samples at 8m).

## `field_*` — FIELD (7 features)

`pressure_at_carrier` (`sample_field` at the carrier's exact position),
`local_mean_pressure`, `local_max_pressure` (whole-grid stats of the
SAME field array), `pressure_gradient_magnitude` (`pressure_gradient`
at the carrier), `pressure_asymmetry` (pressure 2m ahead minus 2m
behind the carrier along the pitch-length axis — a simple, disclosed
directional-imbalance proxy, not a validated asymmetry model),
`contour_coverage_low`/`contour_coverage_high` (fraction of the WHOLE
pitch grid at/above `CONTOUR_LOW`/`CONTOUR_HIGH`).

## `ctx_*` — CONTEXT (8 features)

`pitch_zone_third` (`defensive`/`middle`/`attacking`, by the carrier's
own attacking-direction depth), `pitch_zone_channel`
(`left`/`central`/`right`), `attacking_sign` (±1), `distance_to_goal_cm`,
`touchline_proximity_cm`, `players_visible_this_frame`,
`data_confidence` (= `frame_features`'s own `confidence`),
`data_coverage` (= `frame_features`'s own `coverage`).

## Outcome columns

| column | meaning |
|---|---|
| `heuristic_outcome_raw` | the pipeline's own coarse label (`BALL_REGAIN`/`BACKWARD_ACTION`/`LATERAL_ACTION`/`FORWARD_PROGRESSION`/`UNCERTAIN`), from `attribute_outcomes_all_episodes` |
| `heuristic_outcome` | mapped into the Part 2 taxonomy via `HEURISTIC_TO_TAXONOMY` (`PRESS_LABELING_PROTOCOL.md` §5) |
| `outcome_evidence_id`, `forward_progress_cm` | the real matched pass/turnover id and (for passes) real measured progress in cm |
| `human_outcome`, `final_adjudicated_outcome` | null for every row today — awaiting real manual labels (Part 12) |

**Measured `heuristic_outcome` distribution on this clip: `BALL_REGAIN`
2, `FORCED_BACKWARD` 1, `UNCERTAIN` 16.** The 16 `UNCERTAIN` rows are an
honest reflection of sparse matched evidence within the 3-second
post-episode window (this clip's own possession-resolution sparsity,
not a feature-extraction defect — see `RESEARCH_DATASET_PLAN.md` §1).

## Not included (and why)

- **Defensive-line motion** (team-level, not per-episode) — deliberately
  left out of this per-episode table; it belongs at the frame level,
  already computable from `offside_v4`'s `line_velocity_cm_s` if a
  future join is wanted, not duplicated here.
- Any feature requiring formation/role metadata (e.g. "is this a
  designated presser by tactical role") — not in current tracking data.
